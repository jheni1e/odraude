# Odraude

Odraude is an experimental programming language built from scratch to learn how compilers work.

## Roadmap

- [x] Lexer
- [x] Parser
- [ ] Abstract Syntax Tree (AST)
- [ ] Semantic Analysis
- [ ] JavaScript Generation

## Project Structure

```
src/
├── lexer/
├── parser/
├── ast/
├── semantic/
├── generator/
├── shared/
└── main.ts
```

## Goals

- Learn compiler design
- Understand lexical and syntactic analysis
- Build a complete compilation pipeline
- Generate executable JavaScript
